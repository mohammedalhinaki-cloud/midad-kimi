# مِداد — قليلٌ دائم.. يصنع عالِماً.

منصة إدارة مجموعات القراءة: الأعضاء يقرؤون صفحات يومية داخل الموقع،
والمشرفون المساعدون يديرون الأعضاء والكتب والمتابعة،
والمشرف العام يدير المشرفين المساعدين والنظام.

## البنية التقنية

- **الواجهة:** Vite + JavaScript (بدون إطار عمل)، تُستضاف على **GitHub Pages**.
- **النشر:** **GitHub Actions** يبني وينشر تلقائيًا عند الدفع إلى `main`.
- **قاعدة البيانات والمصادقة والتخزين:** **Supabase** (PostgreSQL + Auth + Storage).
- **العمليات المميزة:** دالة Edge Function واحدة `manage-users` (إنشاء الحسابات،
  تعيين/إعادة تعيين PIN، تغيير الحالات، الحذف النهائي، وتهيئة المشرف الأول).
- **قراءة PDF:** PDF.js داخل المتصفح، مع تحقق من الصفحات على الخادم
  (ترتيب الصفحات + حد أدنى لمدة العرض، بطوابع زمنية من قاعدة البيانات).

## المصادقة

- **الأعضاء:** رقم جوال سعودي + رقم سري من 4 أرقام (بدون OTP وبدون تسجيل عام).
  يُخزَّن الرقم السري داخليًا بصيغة `PIN + MD` لتلبية حد طول كلمة المرور في Supabase Auth.
- **الإدارة:** بريد إلكتروني + كلمة مرور.
- **المشرف الأول:** يُنشأ مرة واحدة عبر رابط «تهيئة النظام» في صفحة الدخول،
  ثم تُعطَّل التهيئة تلقائيًا (لا توجد بيانات اعتماد مكتوبة في الكود).

## التشغيل محليًا

```bash
npm install
npm run dev
```

## النشر

1. ادفع إلى فرع `main` — سيعمل GitHub Actions وينشر إلى GitHub Pages.
2. فعّل GitHub Pages من: Settings → Pages → Source: **GitHub Actions**
   (إن لم يكن مفعّلًا).
3. افتح الموقع واعمل «تهيئة النظام» لإنشاء حساب المشرف الأول.

## ملاحظات أمنية

- مفتاح Supabase المنشور (publishable) موجود في `src/config.js` — آمن للمتصفح
  مع تفعيل RLS على كل الجداول.
- **لا تضع مفتاح service-role/secret في الواجهة أو المستودع أبدًا.**
- ملفات PDF في حاوية خاصة (`books`) وتُقدَّم بروابط موقعة للمستخدمين المسجلين فقط.
- كل التواريخ المعروضة بالتقويم الهجري (أم القرى) بتوقيت `Asia/Riyadh`،
  وتُخزَّن في قاعدة البيانات بصيغة ISO الميلادية.
